## Smart Grasping
**Role:** Project Leader
**Duration:** 2025-2026
**Website:** [Smart Grasping](https://nva.sikt.no/projects/2758466)

It is an early-stage innovation project where the aim is to develop a robust, multi-modal grasping strategy for a 2-finger gripper by using RGB-D data into precise, closed-loop trajectories.


## Sarha - Samordnet datadrevet rehabilitering etter hjerneslag
**Role:** Project member
**Duration:** 2022-2027
**Website:** [Sarha](https://nva.sikt.no/projects/2549654)

The aim is to develop digital solutions to create a more coordinated, data-driven, and personalized rehabilitation process for stroke patients through the integration of sensor technology and machine learning.

## Teknoløft
**Role:** Project member
**Duration:** 2018-2025
**Website:** [Teknoløft](https://nva.sikt.no/projects/573142)

Teknoløft Sogn og Fjordane project aims to build capacity and expertise in digitalisation and automation, on robotics and big data.
